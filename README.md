# CARD GAME

### Release v1.0

Version v0.1 requires at least C++17 & cmake v3.28

### Rules

1. Blacka Jack pays 3:2
2. If **player** has black jack same as **dealer** then it's draw otherwise player lose
3. Inusrance = **player first bet** / 2
4. If dealer's first card is **ACE** player can buy insurance
5. If dealer has black jack game ends immediately
6. If dealer has black jack and player has insurance, player wins insurance
7. Player can double aby time if **player hand value** < 22 | **player has no black jack**
8. Dealer draw on soft 17
9. ENJOY!
